# Security Policy

## Supported Versions

This is a personal portfolio website. As such, only the **latest version** of the code, as available in the `main` branch and deployed to [m-zafari.github.io](https://m-zafari.github.io/), is considered supported.

This site is static and does not handle user accounts, databases, or sensitive personal information.

## Reporting a Vulnerability

I take the security of my website seriously. I appreciate your efforts to responsibly disclose any vulnerabilities you may find.

### How to Report

Please report any suspected security vulnerabilities **privately**. This helps protect the site and its visitors by giving me time to address the issue before it becomes public knowledge.

1.  **Preferred Method:** Please use GitHub's **private vulnerability reporting** feature. You can find this by clicking the "Security" tab on the repository page and then "Report a vulnerability."
2.  **Alternative Method:** If you are unable to use GitHub's private reporting, please email me directly at: `mhdZafari80@gmail.com`

### What to Include

To help me investigate the issue quickly, please include as much detail as possible:

* A clear description of the vulnerability.
* Steps to reproduce the issue (if applicable).
* The potential impact of the vulnerability.
* Any proof-of-concept code or screenshots.

### What to Expect

* I will do my best to acknowledge receipt of your report within **48 hours**.
* I will investigate the issue and keep you updated on the progress.
* Once the vulnerability is confirmed and fixed, I will happily provide public credit for your finding (unless you prefer to remain anonymous).

Thank you for helping keep my portfolio secure!
